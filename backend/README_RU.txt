# Подключение формы к MySQL и Telegram

## 1. База данных
Откройте phpMyAdmin и импортируйте `database.sql`.

## 2. PHP
Откройте `backend/config.php` и укажите:
- данные MySQL;
- токен Telegram-бота;
- ID группы/чата Telegram.

Токен бота никому не публикуйте.

## 3. Telegram
Добавьте бота в нужную группу и дайте ему возможность отправлять сообщения.
В `TELEGRAM_CHAT_ID` укажите ID группы/чата.

## 4. Форма
Главная форма уже отправляет POST-запрос в:
`backend/submit.php`

На хостинге с PHP и MySQL ничего дополнительно в HTML подключать не нужно.

## 5. Важно
Для работы Telegram PHP должен иметь доступ к `api.telegram.org`, а на сервере должен быть включён PHP cURL.
